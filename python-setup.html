Create a Virtual Environment

You may think that this is a bit much right now:) - but it is good practice to set things up right from the start... Virtual environments help you manage dependencies for different projects by isolating them from your global Python installation.

This will become SUPER IMPORTANT in later classes, projects .. whereby you are building different apps that have different dependencies and/or versions.

In order to keep the dependencies local to a particular project, it is highly recommended to use Virtual Environments.

Conventionally one creates, modifies, deletes, customizes virtual environments using commands in the terminal / power shell:

  • Open the Terminal (mac) or Anaconda Prompt (windows) (you should be by default in your home)
  • To create a new environment (<envname> === custom name that you created) AND specify the python version ... and then follow the instructions: 
    
conda create --name <envname> python=3.14
  • To access the created environments - run: 
    
conda info --envs
  • To activate the environment - run: 
    
conda activate <envname>
  • To deactivate the active environment - run: 
    
conda deactivate
  • To delete the an environment - (it must be deactivated first) run: 
    
conda env remove --name <envname>
