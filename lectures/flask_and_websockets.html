FLASK AND WEBSOCKETS

Introduction

WebSocket technology makes it possible to have bi-directional, realtime, interactive communication between a client(s) and a server.
One can send messages to a server (web socket server) and receive responses without having to polling the server for a reply.
Essentially, a persistant connection between client and server is established and both client and server can send/receive data as long as the connection is active.
In order to implement and use: the server MUST be a websocket enabled server, and the client must be a websocket enabled client - hence the need for a WebSocket API ...
Note: Sockets - are NOT specific to Flask or Python... Web socket clients exist for Touch Designer, Unity ....Unreal ... MAxMSp, ... :)


We can use websockets in Flask using the Flask-SocketIO library and as per the documentation it says below:
Flask-SocketIO gives Flask applications access to low latency bi-directional communications between the clients and the server. The client-side application can use any of the SocketIO client libraries in Javascript, Python, C++, Java and Swift,or any other compatible client to establish a permanent connection to the server.

We are now ready to integrate the Socket.io API: which is composed of two parts:

  1. A websocket server: implemented with Flask-SocketIO that integrates with (or mounts on top of) the Flask App (HTTP Server)
  2. A client library: that loads on the browser side: the socket.io client (javascript).

CLIENT -> SERVER HANDSHAKE

Now that we know that client and server have the ability to be connected to each other, we will set up a basic protocol:

  1. Upon loading: the browser is waiting for the user to input a username
  2. Once the username has been entered, the browser will send a join message to the server, using the socket connection.
  3. The server will receive the join message, will store the username in the users list, and will acknowledge the client by sending back a join-complete message
  4. The browser (client) will receive the join-complete message and will know it is able to send messages and is connected ;)
  • In client.js add the event listener for the username: 
    
 document.querySelector("#uButton").addEventListener("click", function(){
        uName = document.querySelector("#uName").value;
        console.log(uName);
      });
  • Then, within the event listener call back add: 
    
  //inital handshake send to server
   clientSocket.emit("join", uName);  // Notify server of new user
  • In socketTest.py add the following decorator function: 
    
# Handle new user joining     
@socketio.on('join')
def handle_join(username):
    users[request.sid] = username  # Store username by session ID
    app.logger.info("in join function")
    app.logger.info(users[request.sid])
    app.logger.info(request.sid)
    # send back message
    emit("join-complete", f"{username} joined the chat")
  • And finally back in client.js, add the callback function: 
    
  //receive notice from server :)
  clientSocket.on("join-complete", function (data) {
    console.log("server registered my join");
    //hide the username input
    document.querySelector(".username-container").style.display = "none"
  });

So now if you test - and add in a username etc ... you should observe that the handshake protocol is in action.
And at this point we have a connection -- YAY..

class Flower{
    constructor(x,y,outer_col,inner_col,scalar){
        this.x = x;
        this.y = y;
        this.o_color = outer_col;
        this.i_color = inner_col;
        this.oscillation_angle =1;
        this.size = 0;
        this.scalar = scalar
    }
    drawFlower(){
        push();
       
        fill(this.i_color);
        ellipse(this.x, this.y-abs(this.size/2), this.size/1.5,this.size/1.5);

        fill(this.i_color);
        ellipse(this.x, this.y+abs(this.size/2), this.size/1.5,this.size/1.5);

        fill(this.i_color);
        ellipse(this.x+abs(this.size/2), this.y, this.size/1.5,this.size/1.5);
         
        fill(this.i_color);
        ellipse(this.x-abs(this.size/2), this.y, this.size/1.5,this.size/1.5);

         fill(this.o_color);
        ellipse(this.x,this.y, this.size/1.8);
        
        pop();
    }
    scaleFlower(){
        this.oscillation_angle+=.03;
        this.size=(sin(this.oscillation_angle)*this.scalar)
    }
}
