User defined CONSTANTS

As you know from other languages like JavaScript, constants are identifiers for values that don’t change during a program’s execution.

Python LACKS built-in syntax for constants, treating them as variables that should remain unchanged.

You define constants by following a naming convention: use all uppercase letters with underscores separating words. This signals to other developers that these variables should not be reassigned. The following example demonstrates creating a constant - and NOTE - that you can change it ... (there will be no warnings from the interpreter).


TEST_ONE = "a constant"
print(TEST_ONE )
TEST_ONE = "changed the constant"
print(TEST_ONE )

A good convention to follow: define constants at the top of any .py file right after any import statements. This way, people reading your code will immediately know the constants’ purpose and expected treatment.
Note: as python has evolved - and is now used readily for larger programs with multiple developers - there are techniques for creating strict user defined constants - but it is beyond the scope of this class...

Defining your own functions I

Let's start with a simple example: lets say we wanted to create a custom function called least_difference that does the following:

  • takes three numbers x1, x2 and x3 as arguments
  • will calculate the differences between x1 and x2 , x1 and x3, x2 and x3
  • returns the minimum difference 


def least_difference(x1, x2, x3):
    #abs() returns the absolute value
    # min() returns the minimum value
    diff1 = abs(x1 - x2)
    diff2 = abs(x1 - x3)
    diff3 = abs(x2 - x3)
    return min(diff1, diff2, diff3)

Lets break it down:

  • We create a function called least_difference, which takes three arguments,x1, x2, and x3.
  • Functions start with a header introduced by the def keyword.
  • The indented block of code following the : is run when the function is called.
  • returnis another keyword uniquely associated with functions. When Python encounters a return statement, it exits the function immediately, and passes the value on the right hand side to the calling context.

Default and Optional Arguments

Information can be passed into python functions as arguments (just like javascript :)). Arguments are specified after the function name, inside the parentheses. You can add as many arguments as you want, just separate them with a comma.

Python also allows for function arguments to have default values . If the function is called without the argument, then the argument gets its default value. This default value is assigned in the function header using the assignment operator (=).

The Syntax:
def function_name(param1, param2=default_value2, param3=default_value3).

The next example demonstrates the importance of the order of arguments given in the function call:


def student(firstname, lastname ='Smith', grade ='Fifth'):
 print(firstname, lastname, 'studies in', grade, 'Grade')
# 1 positional argument
student('Cassandra') 

# 2 positional arguments  
student('Cassandra', 'Parker')                  
student('Cassandra', 'Eighth') # takes second position - so grade will be Fifth

# 3 positional arguments                         
student('Cassandra', 'Parker', 'Eighth')
  • In the first call, there is only one required argument and the rest of the arguments use the default values.
  • In the last call (4th), the lastname and grade arguments values are replaced from the default values to new passing values.
  • In the second and third call only the lastname argument value is replaces from the default to the new ..

You can call functions with keyword argments:


def student(firstname, lastname ='Smith', grade ='Fifth'):
     print(firstname, lastname, 'studies in', grade, 'Grade')

# 1 keyword argument
student(firstname ='Cassandra')     

# 2 keyword arguments                 
student(firstname ='Cassandra', grade ='Eighth')  

# 2 keyword arguments 
student(lastname ='Parker', firstname ='Cassandra')

As you can see from the example, we are using the keyword(s) to specify which argument to replace. Note: it is advisable not to mix the positional with the keyword strategy for the default arguments -> it is one or the other.

The following examples will generate errors:


# required argument missing
student()                

# non keyword argument after a keyword argument              
student(firstname ='Cassandra', 'Fifth') 

# unknown keyword argument 
student(subject ='Maths')

Passing Functions as parameters

We can also create custom functions that accept a function as an argument. Again this should be a familiar concept if you know a bit of javascript: In Python, functions are first-class objects meaning they can be assigned to variables, passed as arguments and returned from other functions. This enables higher-order functions, decorators and lambda expressions (do not worry about these specific terms for now). By passing a function as an argument, we can modify a function’s behaviour dynamically without altering its implementation.

For Example: we want to have a function whose purpose is to apply a function to process text:


def process(alteringFunction, text):  # applies a function to text  
    return alteringFunction(text)  

# function to convert to uppercase
def uppercase(text):  # converts text to uppercase  
    return text.upper()  

print(process(uppercase, "hello"))

# function to replace text with altered text
def replaceText(text):
    return text.replace(text, f"**{text}**")

print(process(replaceText, "good afternoon CART 351!"))

#use same () and pass different functions
itOne = process(uppercase, "double-trouble")
print(process(replaceText, itOne))

Explanation: The function process() applies a any given function to text. We then have defined uppercase() and replaceText(), which get passed as parameters to process().

To loop through a set of code a specified number of times, you can use the range() function.

  • The range() function defaults to 0 as a starting value
  • It is possible to specify the starting value by adding a parameter: range(i, j), which means values from i to j (but not including j)
  • The range() function defaults to increment the sequence by 1, however it is possible to specify the increment value by adding a third parameter k: range(i, j, k).

Another example:

Using else in the for loop

The else keyword in a for loop specifies a block of code to be executed when the loop is finished:

  print(index)

  print("finished for loop!")

for index in range(20):

Break

The break keyword is used to break out a for loop, or a while loop.


for index in range(10):
  print(f"for loop :) {index}")
  if index == 3:

Break & Else

You can use break and else together in a for loop - but note: if the break is executed then the else will NOT run. For example:


def test_break_else(num):
  #go through loop
  for index in range(num):
    print(f"for loop :) {index}")
    #condition for break
    if index == 30:
      print(f"breaking out")
      break
  #come here if we DO NOT break
  else:
    print("finished for loop - num is less than 30!")

  #out of for loop clause
  print(f"out of the foor loop")

test_break_else(20)
test_break_else(40)

join()

If you for instance have a list of words - it is a common task to want to take that list and then 'glue' it back together so that it is a single string again... (go from LIST --> STRING):


element_list = ["hydrogen", "helium", "lithium", "beryllium", "boron"]
glue = ", and "
single_str = glue.join(element_list)
print(single_str)

So, the join() needs a "glue" string to the left - this is the string that will be placed in-between each word in the list. The argument passed to the is the list to convert.

split()

In contrast to join(), split() will take a string and convert to a list :) - This can be useful when you want to apply list operations on a string.

Very often you therefore use split() and join() together:

  1. Split a string to get a list of units (i.e. words)
  2. Use some list operations on the new list
  3. Join that list back together as a string
  4. Do something with the new string

List slicing

List slicing in python is an important strategy that will allow one to easily access specific elements in a list. The syntax is as follows: list_name[start : end : step]
The Parameters are:

  • start (optional): Index to begin the slice (inclusive). Defaults to 0 if omitted.
  • end (optional): Index to end the slice (exclusive). Defaults to the length of list if omitted.
  • step (optional): Step size, specifying the interval between elements. Defaults to 1 if omitted.

NOTE: you can also perform slicing on strings :)

  • To get the items from a list starting at position 1 and ending at position 5 (exclusive): 
    
aList = [1,2,3,4,5,'a','b','c','d','e'] 
print(aList[1:5])
  • Get all the items from a list: 
    
print(aList[::])
print(aList[:])
  • Get all items before/after a specific position: 
    
# Get elements starting from index 2 to the end of the list
bList = aList[2:] #specify start and leave end blank
print(bList)

# Get elements until from start until index 5 
cList = aList[:5] #specify end and leave start blank
print(cList)
  • Get all items between two positions: 
    
# Get elements from index 1 to index 6 (excluding index 6)
dList = aList[1:6]
print(dList)
  • Get items at specified intervals: 
    
# Get every second element from the list, starting from the beginning (use the step)
stepA = aList[::2]
print(stepA)

# Get every third element from the list, starting from index 1 to 8(exclusive)
stepB = aList[1:8:3]
print(stepB)
  • Negative indexing is useful when you want to access elements using indexes starting from the end of the list. The last element always has an index of -1, the second last element -2, and so on....
    Negative indexing makes it easy to access items without needing to know the exact length of the list. 
    
# Get elements starting from index -2 to end of list
negA = aList[-2:]
print(negA)

# Get elements starting from index 0 to index -3 (excluding 3th last index)
negB = aList[:-3]
print(negB)

# Get elements from index -4 to -1 (excluding index -1)
negC = aList[-4:-1]
print(negC)

# Get every 2nd elements from index -8 to -1 (excluding index -1)
negD= aList[-8:-1:2]
print(negD)

#Get from index 1 to last (excluding last)
negE= aList[1:-1]
print(negE)
  • You can also use slicing and replace the items at those indexes: 
    
qList = [1,2,3,4,5,'a','b','c','d','e'] 
qList[0:2] = 'z'    ## replace [1,2] with single ['z']
print(qList)

rList = [1,2,3,4,5,'a','b','c','d','e'] 
rList[0:2] = 'zz'   ## replace [1,2] with ['z','z'] 
print(rList)

sList = [1,2,3,4,5,'a','b','c','d','e'] 
sList[4:-1] = 'nnn'   ## replace
print(sList)
