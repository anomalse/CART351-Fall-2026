FLASK II

Uploading an image :)

In this section we will look at sending multi part form data.
It is a strategy/method for sending multiple types of data in a single HTTP request, commonly used for file uploads and submitting forms with various input types.

Start with this project.
We will use the same HTML form as the one we used to add-to-the-plant-repository,
but we will extend and adapt the functionality to include the ability to upload a file to the web server.
The steps will be:

  • Create a new html template with an HTML form that includes the capability to upload a file as part of the data packet being sent to the server
  • Add a new route to the html in python
  • Update the navigation bar to reference the new link
  • Create another html page (a new thank you page) to route to once the request has been made
  • Create a route for this page - which will also handle the data packet from the form...
  • Save the uploaded file in the correct directory
  • Display the uploaded image in the new thank you page

Again - note that we will complete only the rudimentary steps - i.e. I will not cover checking the file type etc...

  • Make a route and view function in main.py 
    
@app.route("/thank_plant_two",methods = ['POST', 'GET'])
def thank_you_two():
    return render_template("thankyou_plant_rev.html")
    For this HTML form we will be using POST - because you cannot send files / binary data via a GET request... So we need to include the methods attribute to the decorator function.
  • Next: we need to add the action attribute, AND the method, AND **new** the enctype . The enctype attribute specifies how the form-data should be encoded when submitting it to the server - and in this case it will be multipart/form-data .
    Note that the default encoding (if not specified is application/x-www-form-urlencoded). So: replace the form tag in the addPlantExtended.html to: 
    
<form id = "insertPlantForm"
 method = "post" 
action = "{{url_for('thank_you_two')}}" 
enctype="multipart/form-data"
>
  • We will also add some configuration to our flask app:
    1. import the os package (as we will be accessing the file system)
    2. we will need to specify which folder files should be uploaded to
    3. we will set a size limit for the max file size to be uploaded.
    So - fist make a folder inside the static folder of your project and call it uploads.
    Then add the following import statement: 
    
import os
    Next, add the following to main.py: 
    
UPLOAD_FOLDER = 'static/uploads' 
app.config['UPLOAD_FOLDER'] = UPLOAD_FOLDER
app.config['MAX_CONTENT_LENGTH'] = 16 * 1024 * 1024 # 16 MB limit
  • Now we are ready to handle the incoming data packet :): so replace the code in thank_you_two() in main.py with the following: 
    
    if request.method == 'POST':
        #key is the same as in the form :)
        uploadedfile = request.files['the_file']
        #save file to uploads folder
        uploadedfile.save(os.path.join(app.config['UPLOAD_FOLDER'], uploadedfile.filename))
        app.logger.info(uploadedfile.filename)

    return render_template("thankyou_plant_rev.html")
    And test :) - the file should upload...
  • If your logger has output the correct filename and the files has been uploaded successfully -then we can completer the last part! We will pass the filename and the owner name to the template and then display. Since we used the POST method the text data from the form will be accessible via the request.form attribute.
    So, replace the render_template() with: 
    
    return render_template("thankyou_plant_rev.html",
                           imgPath = uploadedfile.filename, 
                           owner = request.form["o_name"])
