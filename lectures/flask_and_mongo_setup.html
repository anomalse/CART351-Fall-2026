FLASK AND MONGODB SET UP

Introduction

  • WHAT IS MONGO DB?
  • In CART 351 we will use the MongoDB Atlas Cloud service with the free sandbox option.
    Why? Well because you can then connect to your database easily from wherever you are! You do not need to worry about security ..etc... and it is a truly scalable option for this class.
  • How will this work? You will have a web server running (php/node.js/flask...) and from the web server you will connect to the mongodb cloud atlas database.
    You need to connect from the webserver - NOT from the client side ..there is a DATA API that allows you to connect that way - but we will not go into that option in this class ...

Create a mongodb atlas account

  1. LINK to mongodb Atlas: and create an account
  2. Once signed in - click on the Create Cluster button - why so that yo can host your database in the cloud for free ;)
  3. Select FREE Shared option. Then keep the default settings for cloud provider and region and click on Deployment button
  4. Your current IP address is automatically added for connectivity: (we will configure later more generallly in the Network Access option ).
  5. Authentication for database access (NOT your mongo db account): has been automatically created. Please do download the .env file - we will need it later.
  6. O.K you have configured your initial setup (you have a project): In the left menu - under the heading Database click on Clusters - you will see the interface for your newly created cluster
  7. Now click on Browse Collections: At this stage we have a sample Database: sample_mflix and sample collections within.
  8. We want our own database and collections ... so right click on the sample_mflix database - ands select to drop it bye!
  9. Then in the main view click on the Create Database button - call it: CART351, and for the collection call it plantRepo. OK you are done for now :)
  10. If you go home/ to a new location: You will need to go to the Database & Network Access option (left main menu) select the IP Access list option.
    Then click on the Add IP Address button and add your current IP Address to the list.

Connect Flask and MongoDB

The next task is to determine and implement the steps to connect a flask appliaction to our mongodb database residing in the cloud.
Python developers can think of MongoDB as a persistent, searchable repository of Python dictionaries :)

  • We need to setup/enable a driver: in this case PyMongo is the official MongoDB Driver for Python. Any python application can use the driver, by importing it and using the MongoClient instance within...
  • As well, there is a widely adopted helper called Flask-PyMongo which is a wrapper around PyMongo, closely integrated with Flask.... which will make our lives much easier :)
  • Create a new project folder (i.e. Cart351Mongo) in VS Code, and activate a virtual environment
  • Create a templates and static folder
  • Create a new python file i.e. testMongo.py

Nice ... ok - but before going further - let's discuss ENVIRONMENT VARIABLES

An env file (or a file containing environment variables) is an important part of both websites and apps. As the developer, you want to take all possible steps to ensure that any sensitive data is protected. So, it is good to be always prepared. So, an environment variable is a variable whose value is set outside the program, typically through a functionality built into the operating system or microservice.

An environment variableis made up of a name/value pair, and any number may be created and available for reference at a point in time.

You will need an env file exactly for the reason that you want to to protect your application sensitive data access, i.e. be API credentials ;).

Remember the .env file that you downloaded when you created your mongodb cluster? ...
Add it into the root of your project folder and rename it to just .env

Note: that this. env file has the key value pairs set up for you in order to connect to your mongodb cluster .... (do not chnage it)

Now we need to use this .env file:

  • Import in testMongo.py: 
    
from dotenv import load_dotenv
import os
  • Within your virtual environment, you will also need to install python-dotenv by running: 
    
pip install python-dotenv
  • And then you can access the those variables in testMongo.py by adding: 
    
load_dotenv()  # Load variables from .env and .flaskenv
db_user = os.getenv('MONGODB_USERNAME')
db_pass = os.getenv('MONGODB_PASSWORD')
print(db_user)

    If you now test - you should be outputting the user name...

Connect to the db::

  • At the top of the script import: 
    
from flask import Flask,render_template,request
# use flask_pymongo instead of  normal pymongo (simplifies integration)
from flask_pymongo import PyMongo
  • Within your virtual environment, make sure to install Flask-PyMongo by running: 
    
pip install Flask-PyMongo
  • Next:: we can set up our flask app and the driver for mongo: 
    
uri = os.getenv("MONGODB_URI")
app = Flask(__name__)
# set a config var
app.config["MONGO_URI"] = uri
mongo = PyMongo(app)
try:
    #get details of the client
    print (mongo.cx)
    print("You successfully connected to MongoDB!")
except Exception as e:
    print(e)

    And test: you should have a success message, as well as output of the details for the mongo client.
    If you have issues make sure your connection string matches the one - that is in your mongodb configuration online...

Next: let's do a test insertion to verify that we can add to our collection and database.

Right now your connection string is not pointing to your cart351 db ... you will need to modify your uri to include the db

  • In the .env add an entry for DATABASE_NAME = CART351
  • In your textMongo.py add the following variable: 
    
db_name = os.getenv('DATABASE_NAME')
  • Now modify your uri to be: uri = uri+f"/{db_name}?retryWrites=true&w=majority"
  • So now we should be able to access the db and the collection: 
    
try:
    #get details of the client
    print (mongo.cx)
    #get db
    print (mongo.db)
    #get collection
    print (mongo.db.plantRepo)
    print("You successfully connected to MongoDB!")
except Exception as e:
    print(e)
  • So - if you have success - then we should be able to insert a test:
