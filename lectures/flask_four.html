Reading/ writing to a text file

Python provides built-in functions for creating, writing and reading files.
Two types of files can be handled in Python, normal text files and binary files.

  • Text file: Each line of text is terminated with a special character called EOL (End of Line), which is new line character '\n' in Python by default.
  • Binary files: There is no terminator for a line and data is stored after converting it into machine-understandable binary format.
  • To open a file: use the open()function: file_object = open("File_Name","Access_Mode")
  • An example: let's utilize the following texts:download the folder here.
    Create a new project - new environment etc in VS Code and add the files folder into the project root.
    Also create a python file called fileOps.py.
  • Now to open the rainbow.txt file: 
    
# Open rainbow.txt in append mode
rainbowFile = open("files/rainbow.txt", "a")

    We can open as many files as we want at one time, as long as they are all assigned to different variables.. ie: 

    
# Open sample_text.txt with write+ mode
st = open("files/sample_text.txt", "w+")
    Also note the second parameter: the mode: can take on different representations:
    • r – Read-only mode. This mode allows you to read from the file, but you can’t make any changes to it. It raises an error if the file is not existing on your system.
    • w – Write-only mode. This mode allows you to write to the file, but you can’t read from it. It creates the file if it does not exist on your system. It will overwrite if the file is present in your system.
    • a – Append-only mode. This mode allows you to write to the file, but you can’t read from this mode. It creates the file if it does not exist on your system. It will add new data if the file already has data.
    • r+ – Read + Write mode. This mode allows you to read from and write to the file. It raises an error if the file is not existing on your system.
    • w+ – Write + Read mode. This mode allows you to read from and write to the file. It creates the file if it does not exist on your system. It will overwrite if the file is present in your system.
    • a+ – Append + Read mode. This mode allows you to read from and write to the file. It creates the file if it does not exist on your system. It will add new data if the file already has data.

Reading a Text file

There are three ways to read a text file:

  • read(): Returns the read bytes in form of a string. Reads "n" number bytes, if no "n" specified, reads the entire file. file_object.read([n])
    In the case of the rainbow.txt: -- also note the use of seek() in the example: 
    
rainbowFile_r = open("files/rainbow.txt", "r")
#read first 4 bytes (1 char per byte)
out4 = rainbowFile_r.read(4)
print(out4)
#read entire text - but note if we read before... 
# then we will be reading from where we read last...
#and once it has consumed the entire file - you can no longer read...
out_all = rainbowFile_r.read()
print(out_all)
#so to go back to start then - > use the seek function...
rainbowFile_r.seek(0)
out_all_a = rainbowFile_r.read()
print(out_all_a)
  • readline(): Reads one line of the file and returns in form of a string. For specified number 'n', reads at most n bytes.
    However, this function does not reads more than one line, even if the number 'n' exceeds the length of the line: 
    
#go back to beginning
rainbowFile_r.seek(0)
oneLine = rainbowFile_r.readline()
print(oneLine)
  • readlines(): Reads all the lines and return them as each line a string element in an iterable list. 
    
#go back to beginning
rainbowFile_r.seek(0)
#stored in a list - each line is one element in the list
allLines = rainbowFile_r.readlines()
print(allLines)
print(allLines[0])

Writing a Text file

There are two ways to write in a file:

  • write(): Inserts a given string in a single line in the text file. file_object.write(str)
    Let's duplicate sample_text.txt - and call it sample_text_rev.txt - we will write to this file... so first open it: 
    
sampleFile = open("files/sample_text_rev.txt", "w")

    Then we will ask the user for input three times - and every time we will add the input to the file: 
    
for i in range(3): 
    a_name = input("Enter the name of the animal: ") 
    sampleFile.write(a_name) 
    sampleFile.write("\n") 
sampleFile.close() 
print("Data is written into the file.")
    Note - that you are NOT appending to the file - rather you are overwriting the file each time you open it.
  • writelines(): For a list of string elements, each string is inserted in text file.
    This function is thus used to insert multiple strings at a single time: file_object.writelines(l) where l = [str1, str2, str3]
    Example: 
    
colorList = [] 
for i in range(3): 
    a_name = input("Enter the name of a color: ") 
    colorList.append(a_name + '\n') 
sampleFile.writelines(colorList) 
sampleFile.close() 
print("Data is written into the file.")

Appending to a Text file

If we do not want to ot overwrite a file - but rather append to the file - we will open the file in the append mode and then either call write() or writelines():


sampleFile_a = open("files/sample_text.txt", "a")

    a_name = input("Enter the name of someone in your class: ") 
    nameList.append(a_name + '\n')

print("Data is written into the file.")

Writing JSON

Writing data to a JSON file in Python involves converting Python objects like dictionaries into JSON format and ten saving them to a file.
This process is called serialization. Let's explore two methods to write a JSON file in Python:

Using json.dumps()

json.dumps() is a function that helps converting a dictionary to a JSON object. It takes two parameters:

  1. the dictionary: the name of a dictionary which should be converted to a JSON object.
  2. indent:defines the number of units for indentation.

After converting the dictionary to a JSON object, simply write it to a file using the write() function - as was discussed with text files :):


data_toSave = {"name":"mandy", "fav_col":"blue", "fav_city":"winnipeg"}
#convert dictionary to str
jsonStr = json.dumps(data_toSave, indent=4)
#open or create if non existent
fileOpen = open("files/new_sample.json","w")
fileOpen.write(jsonStr)

Using json.dump()

Another way of writing JSON to a file is by using json.dump() method.
This function writes the dictionary to a file in the form of JSON, without needing to convert it into an actual JSON object.


jsonFile = open("files/new_sample_b.json", "w")
data_toSave_2= {"name":"mandy", "fav_col":"blue", "fav_city":["list",3,4,True,"abc"]}
json.dump(data_toSave_2,jsonFile, indent =4)
