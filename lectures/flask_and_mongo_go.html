CREATE A SCHEMA

Creating the database is the easy part and a single collection is easy....
The harder part is deciding what the structure of the collections(s) should be: the design is very important.
We start with asking the following questions:

  1. What are and how many collections do we need?
  2. What are the properties that should be in each of them?

We know that we want a collection that contains a record / document (an entry) for each of the plant items.
Each entry should contain, as a bare minimum, the name of each plant item. Because the name by itself is not very interesting, the collection should contain other information: For example, if the same person uploads different plants we may want to list all the plants uploaded by a specific person.
Maybe we also want to keep some basic descriptive information such as:

  • geographic location
  • birth date
  • a description
  • and a visual document (i.e. an image)

Please Note:it is up to you as the developer to decide what fields you want in the collection - depending on the content, context and usage (i.e. what kind of queries do you want to implement).

AND - OR

We can define a range of valid dates using the logical operator $and:
Note the structure:


    endTime = datetime.strptime("2010-01-12", format_string)
    result = mongo.db.plantRepo.find(
        {'$and':[{'birthDate':{'$gt':startTime}},{'birthDate':{'$lt':endTime}} ]})

We van also use the use the logical operator $or:


  result = mongo.db.plantRepo.find(
        {'$or':[{'owner_name':'Sarah'},{'owner_name':'Martha'} ]})

SORT

We can also sort the output results using specific fields.
You specify how you want to sort as a set of options to the query:


   result = mongo.db.plantRepo.find(
        {'$or':[{'owner_name':'Sarah'},{'owner_name':'Martha'}]}).sort("birthDate",1)

Here - we are sorting by creation date smaller-larger ... if we change to -1, then it would be the opposite direction.

LIMIT

We can limit the number of results.
In the next example we will SORT and LIMIT the number of results:


      result = mongo.db.plantRepo.find(
        {'$or':[{'owner_name':'Sarah'},{'owner_name':'Martha'}]}).sort("birthDate",-1).limit(2)

SELECTING FIELDS

Up till now: we have by default put out all the fields in our results .
BUT this is not necessary -> we can choose which fields to output by further refining the query using the projection option:

We specify a (0) if we do want to include a field that wouly by default be included (the id), and a 1 for those we want included
All the ones we DO NOT want included: we will not list in the options. i.e.: 


  options = {'_id':0,'owner_name':1,'plant_name':1,'imagePath':1}
   result =  mongo.db.plantRepo.find({},options)

And note we can still include our other options in the query: sort, project and limit.


    result = mongo.db.plantRepo.find(
     {'$or':[{'owner_name':'Sarah'},{'owner_name':'Martha'}]},options).sort("birthDate",-1).limit(3)

RETRIEVE FROM DB USING FETCH ...

Last thing and then we are done... lets look at how to retrieve from mongodb in a more dynamic way instead of hardcoding our queries in the python script:

  1. Create a new html page that contains a search field.
  2. Then when the user makes a search request -> we make a GET request to the Flask Application passing the search value.
  3. Our Flask Application receives the GET request - and makes a query to the mongo db
  4. Mongodb returns the results to the Flask Application
  5. Flask encodes the results as JSON and sends back the response
  6. Client side JS receives the response and outputs the result to the html

      back.appendChild(container);

      let contentContainer = document.createElement("div");
      contentContainer.classList.add("content");
      container.appendChild(contentContainer);

      for (let property in theResult[i]) {
        console.log(property);

        if (property !== "imagePath" && property !== "birthDate") {
          let para = document.createElement("p");
          para.textContent = property + ":" + theResult[i][property];
          contentContainer.appendChild(para);
        }
        if(property ==="birthDate"){
          let para = document.createElement("p");
          let options = { weekday: 'long', year: 'numeric', month: 'long', day: 'numeric' };
          let date = new Date(theResult[i][property]["$date"])
          para.textContent = property + ":" + date.toLocaleDateString("en-US", options);
         contentContainer.appendChild(para);
        }
      }
      let img = document.createElement("img");
      img.setAttribute("src", "../static/"+theResult[i]["imagePath"]);
      container.appendChild(img);
    } //outer for
  }
