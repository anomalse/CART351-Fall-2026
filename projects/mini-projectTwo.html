TECHNICAL DESCRIPTION

The goal of this project is to create a *COMPLETE FUNCTIONAL FLASK APPLICATION*.
You will be implementing both the front end(HTML, CSS, JS) and backend (Flask and Python).

has to have the following new/additional features (along with the requirements from mini-project-one:

  1. takes input from users, saves that input permanently to a MongoDB database (cloud hosted) .
  2. retrieves data from the MongoDB database (see above), based on at least one query/condition specified by the client
  3. is visually rich, tantalizing, playful, unexpected, suprising
  4. holds the client's focus and attentionfor a good period of time (is engaging)
  5. changes over time ... (is a living application) i.e. if I visit it today and tomorrow - when I visit it tomorrow something may have changed...
  6. allows users to experience some representation: using the data that is stored in the json file(s) server side - as well as other data sets if you wish :)
