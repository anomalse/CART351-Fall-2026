2: A GET Request to retrieve search criteria and display single result

Ok - you already have the route:"/t1" and the associated view function defined - uncomment it :).
  1. Add a link in the nav bar to this html page (hint: use url_for()in base.html)
  2. Create the specified HTML template - and make sure it inherits from base.html.
  3. Design an html page that is visually enticing (layout, color choices do matter :) The page needs to include:
    • An HTML form with a text input field and a submit button
    • A placeholder container for possible result data: a textual description and an image
  4. Implement a GET request to pass the user input to the server... note that in your python script the route ("/getSearchCriteria") & associated function has already been set up.
  5. In the python script: exercise-two.py -> at the function associated with the route ("/getSearchCriteria") implement the following:
    • Take the user input from the client (hint - see : request.args) and formulate the url to pass to the NASA Image API:
      • the base url: https://images-api.nasa.gov/search
      • the search parameter:q= <user input>
      • the media type parameter:media_type=image
    • Use the requests module to perform the API request (hint: remember Star Wars)
    • Use the json() function to retrieve the result
    • Access the data['collection']['items'] part of the result ... it is a list.
      1. Access the first element in the list - which is a dictionary.
      2. Access the first image href attribute from the links key and store the result in a variable called imgFromNasa.
      3. Access the first description attribute from the data key and store that result in a variable called description.
    • The code to format the url is properly has already been done for you as well as the return statement (render_template....) - DO NOT CHANGE IT
  6. On the client side: t1.html: ensure that the description and image are being displayed...
  7. Finally: write the logic (using Jinja), using the have_results variable: only show the container with image and description when that variable is set to True.
