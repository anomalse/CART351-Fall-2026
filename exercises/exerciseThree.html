BACKGROUND

This is a fictional survey that I dreamt up : we would like to explore how participating in a specific event affects ones mood given certain weather conditions and a specific date(day).

Let us imagine that we have done an online survey.

We have asked 1000 participants to:

  1. Select an event that they have recently done from a predetermined list
  2. They will then select their mood before and after the event occurred (from predetermined lists)
  3. They would also rate the strength (1-10) of their after mood & the affect strength of the event.
  4. They would also specify the day and weather conditions when the event occurred

In reality – this dataset of 1000 entries will be constructed automatically using randomized input. DO NOT add new data or remove data from the dataset - once you have initially created it.

PART III: WRITE THE QUERIES

You will see in server.py the routes are already created for each query ("three","four","five" and "six"). You job here is to write the correct query for each and access the relevant result object for each -- see routes "one" and "two" for help...

  • three: Select all entries in the collection where the after_mood is positive
  • four: Select all entries in the collection & sort each entry by associated event name
  • five: Select all entries in the collection that occur on a Monday or a Tuesday and sort them by the event_affect_strength
  • six: Select all entries in the collection where both the start_mood and after_mood fall into the negative category and sort the entries by weather.

N.B : You must use mongodb to obtain the correct results. Do not implement any filtering strategies on the client side in js !

It is recommended that you test the results using the already created route:debugView. If you go to that page, and select from the drop down list, you should, without having to change any code, be able to get raw output in the page for each completed query.
