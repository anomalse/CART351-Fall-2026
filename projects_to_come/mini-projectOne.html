TECHNICAL DESCRIPTION

The goal of this project is to create a *COMPLETE FUNCTIONAL FLASK APPLICATION*.
You will be implementing both the front end(HTML, CSS, JS) and backend (Flask and Python).


What FORM of Application you ask?

  • A game?
  • A narrative?
  • An interactive Experience?
  • A Data Visualization?
  • An abstract experience?
  • A sound based experience?

Well... it can be any of these... as long as the application has the following features:

  1. It responds to the Conceptual Description (above)
  2. takes input from users, saves that input permanently to (a) json file(s) server side (output).
  3. allows users to experience some representation: using the data that is stored in the json file(s) server side - as well as other data sets if you wish :)
